Quartermaster 6.6 adds more draft validation and solidifies the essentials.

## 📱 Improving the Essentials

Most edits can be undone by shaking your iPhone, or using the command menus on iPad. The file loading and syncing system is now more efficient, and you can draft using multiple iPad windows.

## ✅ Detailed Draft Validation

Set percentage-based calculations to exact or rounded values and highlight errors with Role limitations.

## 🎛️ New Upgrade Settings

Unit upgrades and Detachment definitions can now start with a set minimum, and Units can have their points cost multiplied.

**Available now in the [App Store](https://apps.apple.com/app/quartermaster/id879731050).**
