The [Necromunda faction templates](https://templates.quartermaster.app/GW.html#Necromunda) have been overhauled to reduce file sizes and improve efficiency.

- A new **Crew** role has been added and existing Crew and Vehicles have been moved in the affected faction templates. You’ll need to re-install the [Necromunda game system](https://templates.quartermaster.app/GW.html#Necromunda) and any relevant templates to access these changes. The Crew role won’t work with existing drafts, you’ll need to create new drafts before adding Crew.
- Generic vehicles are now only available from the [Vehicles](https://templates.quartermaster.app/GW.html#Necromunda-Vehicles) template. Install the template, then you can add any Vehicles you need to your gang by tapping the **+ Add** button, selecting the **Add from another faction** option at the bottom of the list, and then choosing **Vehicles**. If you’re still using Quartermaster 5, you can only add Vehicles as an allied detachment.
- Campaign tracking options are now available from a new [Campaigns template](https://templates.quartermaster.app/GW.html#Necromunda-Campaigns). This reduces file sizes since you’re only ever playing one campaign at a time. Install the template, then you can add any Campaign trackers you need to your gang by tapping the **+ Add** button, selecting the **Add from another faction** option at the bottom of the list, and then choosing **Campaigns**. If you’re still using Quartermaster 5, you can only add Campaigns as an allied detachment.
