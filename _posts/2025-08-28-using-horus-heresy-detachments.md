Quartermaster 6.5 includes a rethinking of the existing Detachment capabilities to enable better drafting for Horus Heresy 3rd Edition.

When you create a new Horus Heresy draft, you’ll start with any compulsory Detachments. Tap a Detachment to expand the view; from there you can add Units to the Detachment.

![]({{ '/assets/posts/793101846013165568/1.jpg' | relative_url }})

When you go back to the main Draft view, you’ll see all the Units for your Detachments listed in a condensed format.

![]({{ '/assets/posts/793101846013165568/2.jpg' | relative_url }})

To add more Detachments, tap the Add button at the Draft view. Detachments are indicated with an icon in the list.

![]({{ '/assets/posts/793101846013165568/3.png' | relative_url }})

To add a Detachment from a different Faction, tap the Faction name at the top, then use the picker to choose a different Faction. Usually you’ll start with an Allied Detachment. Every Detachment added this way then uses Units from the source Faction.

![]({{ '/assets/posts/793101846013165568/4.png' | relative_url }})

Some situations allow you to add extra Battlefield Roles to a Detachment. To do this, when adding Units to a Detachment, use the picker to change the “Add units to” setting. Additional Battlefield Roles are listed there.

![]({{ '/assets/posts/793101846013165568/5.png' | relative_url }})

On the main Draft view, you can check your Detachment allowances by tapping the total points in the top right. This will update based on which High Command and Command choices you have selected.

![]({{ '/assets/posts/793101846013165568/6.png' | relative_url }})

Expanding the points total at the top gives a full breakdown of all your Detachments, which can be further expanded to explore the breakdown of each Detachment.

![]({{ '/assets/posts/793101846013165568/7.png' | relative_url }})

And that’s Detachments in Quartermaster 6.5.
