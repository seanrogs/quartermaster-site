The [Horus Heresy games system and factions templates](https://templates.quartermaster.app/HH.html#HH) have been updated with the latest content from Book Eight: Malevolence.

Each faction has been given access to Psyarkana. Download the Horus Heresy game system fresh to get access to all the generic Psyarkana Relics.

The Legiones Astartes faction has been updated with all the new units and rules. In addition, you can now use the Legiones Astartes faction template to create Blackshields armies rather than the old and out-of-date Blackshields faction template.
